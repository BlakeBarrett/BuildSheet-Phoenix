February 2026
Safety Auditor + Voice Mode
Feature

Launched the Safety Auditor panel — validate your BOM against configurable compliance checks with structured add/remove actions. Added "Greasy Hands" Voice Mode (Pro+): push-to-talk hands-free assistant using browser SpeechRecognition and SpeechSynthesis with Gemini context.

January 2026
Visual Assembly Block Diagram
Feature

The Chilton Visualizer now renders an interactive SVG block diagram of your build's component relationships. Blocks are clickable (jumps to BOM entry), pan/zoom enabled, with port connection lines and color-coded port types.

January 2026
CSV & Paste BOM Import
Feature Export

Import a BOM from CSV (drag-and-drop or file picker) with auto-detected column mapping. Paste a free-text parts list and AI parses it into structured BOM entries. CSV export added to the nav rail.

January 2026
PDF Export
Export

Export your BOM as a print-optimized PDF directly from the app. Includes all components, SKUs, quantities, pricing, and total cost estimate.

Beta Launch
Feature

Public beta launched. Google Sign-In, Firestore-backed projects, project sharing via base64 URL, sub-assembly nesting, undo/redo, OpenSCAD enclosure generation, and STL preview via Three.js.
